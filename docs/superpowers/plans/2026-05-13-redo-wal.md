# Redo-Log WAL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Switch from undo-log WAL (before-images, 2 disk writes per commit) to redo-log WAL (after-images, 1 disk write per commit) to halve Normal durability I/O overhead.

**Architecture:** `WriteGuard::commit()` returns dirty page data (after-images) instead of before-images. `commit_write` writes after-images to WAL only, never to the data file. Crash recovery replays WAL forward (apply) instead of backward (undo). Data file flushed on clean shutdown.

**Tech Stack:** Rust, existing boogy-db crate.

**Spec:** `docs/superpowers/specs/2026-05-13-redo-wal-design.md`

## Task 1: Simplify WriteGuard — Remove Before-Images, Return After-Images

**Files:**
- Modify: `src/file.rs`

The WriteState currently tracks `before_images` (old page data for undo). With redo-log, we don't need before-images at all. `commit()` returns the dirty page data directly (these ARE the after-images).

- [ ] **Step 1: Remove before_images from WriteState**

In `WriteState`, remove:
- `before_images: Vec<Option<Box<[u8; PAGE_SIZE]>>>`
- `capture_before_images: bool`

```rust
pub(crate) struct WriteState {
    dirty: HashMap<u32, Box<Page>>,
    new_page_count: u32,
}
```

Update `PageFile::open` to not initialize before_images fields.

Remove `set_capture_before_images` method from PageFile.

- [ ] **Step 2: Remove before-image capture from WriteGuard methods**

In `WriteGuard::write_page()`, remove the before-image capture block:
```rust
// REMOVE this block:
if self.state.capture_before_images {
    ...
    self.state.before_images[idx] = Some(Box::new(current.data));
    ...
}
```

Just load the page into dirty and mark it dirty. No before-image.

In `WriteGuard::put_page()`, remove the before-image capture block similarly.

Remove `take_before_images()` and `take_before_images_inner()` methods entirely.

- [ ] **Step 3: Simplify commit() — return after-images, no flush_to_disk**

Change signature from `commit(self, flush_to_disk: bool) -> Result<Vec<(u32, [u8; PAGE_SIZE])>>` to `commit(self) -> Result<Vec<(u32, [u8; PAGE_SIZE])>>`.

The returned Vec contains `(page_no, new_page_data)` — these are the after-images.

```rust
pub fn commit(self) -> Result<Vec<(u32, [u8; PAGE_SIZE])>> {
    // Collect after-images (dirty page data) BEFORE publishing to cache.
    let after_images: Vec<(u32, [u8; PAGE_SIZE])> = self.state.dirty
        .iter()
        .map(|(&page_no, page)| (page_no, page.data))
        .collect();

    // Publish to shared cache.
    let new_page_count = self.state.new_page_count;
    let np = self.file.num_pages.load(Ordering::Relaxed);
    let new_total = np + new_page_count;

    {
        let mut cache = self.file.pages.write().unwrap();
        while cache.len() < new_total as usize {
            cache.push(None);
        }
        for (&page_no, page) in &self.state.dirty {
            cache[page_no as usize] = Some(Arc::new((**page).clone()));
        }
    }

    if new_page_count > 0 {
        self.file.num_pages.fetch_add(new_page_count, Ordering::Relaxed);
    }

    // Clear write state.
    self.state.dirty.clear();
    self.state.new_page_count = 0;

    Ok(after_images)
}
```

No `flush_to_disk` parameter. The data file is NEVER written during commit. That's the whole point.

- [ ] **Step 4: Update discard()**

Remove before_images cleanup from discard — there are no before-images anymore:

```rust
pub fn discard(mut self) {

    self.state.new_page_count = 0;

```

## Task 2: Rewrite commit_write, Crash Recovery, and Drop

**Files:**
- Modify: `src/db.rs`

- [ ] **Step 1: Rewrite commit_write**

```rust
fn commit_write(
    guard: WriteGuard,
    wal: &Mutex<Wal>,
    durability: Durability,
    table_id: u32,
) -> Result<()> {
    let after_images = guard.commit()?;
    match durability {
        Durability::Immediate => {
            let mut wal = wal.lock().unwrap();
            for (page_no, data) in &after_images {
                wal.append_before_image(table_id, *page_no, data)?;
            }
            wal.sync()?;
        }
        Durability::Normal => {
            let mut wal = wal.lock().unwrap();
            for (page_no, data) in &after_images {
                wal.append_before_image(table_id, *page_no, data)?;
            }
            // No sync — OS buffer survives process crash
        }
        Durability::None => {
            // after_images dropped — no WAL write
        }
    }
    Ok(())
}
```

Note: We keep calling `wal.append_before_image` (the method name is misleading now — it's actually appending after-images). The method signature is unchanged: `append_before_image(table_id, page_no, &[u8; PAGE_SIZE])`. Renaming it is optional cleanup.

Key change: no `guard.commit(true)` — the data file is never written during commit.

Also: no `wal.truncate()` after Immediate. The WAL accumulates entries and is truncated on checkpoint (shutdown).

- [ ] **Step 2: Rewrite crash recovery in open()**

Change from backward (undo) replay to forward (redo) replay:

```rust
// Step 1: Crash recovery -- replay WAL forward (redo).
{
    let mut wal = Wal::open(&wal_path)?;
    if wal.entry_count() > 0 {
        let file = PageFile::open(&path)?;
        let entries = wal.read_entries()?;
        // Redo: apply after-images in forward order.
        for entry in &entries {
            let page = Page::from_bytes_unchecked(entry.page_data);
            file.put_page_direct(entry.page_no, page);
        }
        file.sync_all()?;
        wal.truncate()?;
    }
}
```

The only change: `entries.iter().rev()` becomes `entries.iter()` (forward instead of reverse).

- [ ] **Step 3: Update Drop (checkpoint)**

The Drop impl needs to flush all cached pages to the data file (checkpoint):

```rust
impl Drop for BoogyDb {
    fn drop(&mut self) {
        // Checkpoint: persist registry, flush all pages to disk, truncate WAL.
        let (metas, next_id) = self.snapshot_table_metas();
        {
            let mut guard = self.file.begin_write();
            if self.file.page_count() == 0 {
                let _ = guard.allocate_page();
            }
            let page = serialize_system_page(&metas, next_id);
            guard.put_page(0, page);
            let _ = guard.commit(); // publish system page to cache
        }
        // Flush ALL cached pages to data file.
        let _ = self.file.sync_all();
        // Truncate WAL — all data is now in the data file.
        if let Ok(mut wal) = self.wal.lock() {
            let _ = wal.truncate();
        }
    }
}
```

- [ ] **Step 4: Update persist_registry**

The `persist_registry` helper calls `commit_write`. Since `commit()` no longer takes `flush_to_disk`, this should just work. But check the call and make sure it compiles.

- [ ] **Step 5: Remove set_capture_before_images calls**

In `set_durability()`, remove the `self.file.set_capture_before_images(...)` call. The method no longer exists.

# Lazy Row Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace eager Row decoding with a lazy wrapper around raw bytes to eliminate ~8µs of decode overhead per indexed find call.

**Architecture:** Row stores raw bytes + shared Arc<Vec<String>> column names. Decode happens on demand via `row.get(name)` or `row.columns()`. Internal paths (update, delete) use `decode_row` directly without building Row. Filter evaluation in find/multi-filter paths uses `extract_column_raw` + `eval_filter_raw` on raw bytes.

**Tech Stack:** Rust, existing boogy-db crate, `std::sync::Arc`.

**Spec:** `docs/superpowers/specs/2026-05-13-lazy-row-design.md`

With:

```rust
use std::sync::Arc;

/// A row returned from queries. Wraps raw bytes; decodes on demand.
#[derive(Debug, Clone)]
pub struct Row {
    pub id: u64,
    data: Vec<u8>,
    col_names: Arc<Vec<String>>,
}

impl Row {
    /// Create a lazy Row from raw encoded bytes and shared schema.
    fn from_raw(bytes: &[u8], col_names: Arc<Vec<String>>) -> Result<Self> {
        let id = row::extract_id(bytes)?;
        Ok(Self {
            id,
            data: bytes.to_vec(),
            col_names,
        })
    }

    /// Get a single column value by name. Decodes only that column.
    pub fn get(&self, column: &str) -> Option<Value> {
        let col_id = self.col_names.iter().position(|n| n == column)? as u16;
        row::extract_column(&self.data, col_id).ok().flatten()
    }

    /// Decode all columns. Use when you need every column value.
    pub fn columns(&self) -> Vec<(String, Value)> {
        match row::decode_row(&self.data) {
            Ok(decoded) => decoded
                .columns
                .into_iter()
                .filter_map(|(col_id, val)| {
                    self.col_names
                        .get(col_id as usize)
                        .map(|name| (name.clone(), val))
                })
                .collect(),
            Err(_) => Vec::new(),
        }
    }
}
```

- [ ] **Step 4: Update indexed find path**

Replace the decode loop in the index path of `find()`:

```rust
// Old:
let mut rows = Vec::with_capacity(raw_rows.len());
for bytes in &raw_rows {
    let decoded = row::decode_row(bytes)?;
    let row = decoded_to_row(decoded, &state.meta);
    if has_extra_filters {
        let passes = opts.filters.iter().all(|f| {
            let col_val = row.columns.iter()
                .find(|(name, _)| name == &f.column)
                .map(|(_, v)| v);
            match col_val {
                Some(v) => f.matches(v),
                None => f.matches(&Value::Null),
            }
        });
        if passes { rows.push(row); }
    } else {
        rows.push(row);
    }
}

// New:
let col_names = state.meta.col_names.clone();
let mut rows = Vec::with_capacity(raw_rows.len());
for bytes in &raw_rows {
    if has_extra_filters {
        // Use raw-byte filter evaluation — no decode needed
        let passes = opts.filters.iter().all(|f| {
            if let Some(col_id) = state.meta.col_id(&f.column) {
                if let Ok(Some(raw)) = row::extract_column_raw(bytes, col_id) {
                    if let Some(result) = crate::filter::eval_filter_raw(raw, &f.op, &f.value) {
                        return result;
                    }
                }
                // Fallback: decode the column
                let col_val = row::extract_column(bytes, col_id).ok().flatten();
                let actual = col_val.as_ref().unwrap_or(&Value::Null);
                f.matches(actual)
            } else {
                f.matches(&Value::Null)
            }
        });
        if passes {
            rows.push(Row::from_raw(bytes, col_names.clone())?);
        }
    } else {
        rows.push(Row::from_raw(bytes, col_names.clone())?);
    }
}
```

- [ ] **Step 8: Update sort to use row.get()**

```rust
// Old:
matching.sort_by(|a, b| {
    let va = a.columns.iter().find(|(n, _)| n == &sort.column).map(|(_, v)| v);
    let vb = b.columns.iter().find(|(n, _)| n == &sort.column).map(|(_, v)| v);
    ...
});

// New:
matching.sort_by(|a, b| {
    let va = a.get(&sort.column);
    let vb = b.get(&sort.column);
    let ord = match (&va, &vb) {
        (Some(a), Some(b)) => a.compare(b).unwrap_or(std::cmp::Ordering::Equal),
        (Some(_), None) => std::cmp::Ordering::Greater,
        (None, Some(_)) => std::cmp::Ordering::Less,
        (None, None) => std::cmp::Ordering::Equal,
    };
    match sort.dir {
        SortDir::Asc => ord,
        SortDir::Desc => ord.reverse(),
    }
});
```
